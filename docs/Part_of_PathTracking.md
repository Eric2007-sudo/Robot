<h1 align="center">Part of Path Tracking</h1>

这份文档以纯追踪（Pure Pursuit）作为局部控制参考算法，介绍拿到全局路径后如何让差速底盘沿路径运动。作业允许使用其他合理的路径跟踪方法，验收不要求复现纯追踪的固定公式。

读完你应该能写出 `pure_pursuit.cpp` 里的 `computeCommand`，并让它通过单元测试。

## 一、差速底盘的运动学

本题的车是**差速底盘**：左右两个轮子。它的运动由两个量描述：

- 线速度 `v`：车沿**车头方向**前进的速度（m/s）；
- 角速度 `ω`：车绕自身中心旋转的速度（rad/s）。

差速底盘的运动学很简单：

```
dx/dt = v · cos(θ)
dy/dt = v · sin(θ)
dθ/dt = ω
```

两个轮子怎么变成 `(v, ω)` 是底盘（下位机）的事，导航只负责算出 `(v, ω)` 发给它。ROS 2 里这就是 `geometry_msgs/Twist`：`linear.x` 填 `v`，`angular.z` 填 `ω`。

一个关键性质：**差速底盘的最小转弯半径由 `v` 和 `ω` 共同决定**，曲率 `κ = ω / v`。`ω` 越大、`v` 越小，转得越急。

## 二、纯追踪的思想：追一个"前瞻点"

路径是一串坐标点，车在某个位置。纯追踪不问"我离路径最近的点在哪"，而是问一个更前向的问题：

> **在路径前方选一个点（前瞻点），转一个圆弧去追它。**

为什么追"前方"而不是追"最近"？追最近点有个毛病：车一旦略微偏离路径，最近点可能跳变，车就会抖。追前方一点则平滑得多——车始终"望着"路径前方一小段距离的点走。

## 三、前瞻点怎么选

两步：

**1. 找最近点。** 遍历路径，找到离车当前位姿最近的那个路径点，记索引 `i_nearest`。

**2. 从最近点出发，沿路径向前，找前瞻点。** 从 `i_nearest` 开始向后（索引递增）扫，返回第一个满足 `距离(车, path[i]) >= lookahead_distance` 的点；到路径末端都没找到，就用最后一个点。

前瞻点是路径上距离机器人至少 `lookahead_distance` 的第一个离散点，不一定与机器人正好相距这个距离。若扫描到路径末端仍没有满足条件的点，就使用最后一点，避免访问越界。

最近点只用于确定扫描起点，真正用于曲率计算的是前瞻点。`lookahead_distance` 的单位是米，本题默认值为 `0.5`。

## 四、曲率公式：怎么转才能到前瞻点

车在 `(x, y, θ)`，前瞻点 `G = (gx, gy)`。先把 `G` 变换到**车体系**：

```
dx = gx - x
dy = gy - y
lx =  cos(θ) · dx + sin(θ) · dy   # G 在车前方多远
ly = -sin(θ) · dx + cos(θ) · dy   # G 在车左方多远
```

`(lx, ly)` 是前瞻点在车体系下的坐标：`lx` 是前向分量，`ly` 是左向分量。**`ly > 0` 表示前瞻点在车左侧，`ly < 0` 在右侧。**

纯追踪假设车沿一个**与车头相切、经过前瞻点**的圆弧走。设圆弧半径 `R`、曲率 `κ = 1/R`，用几何可以推出（圆心在车体 y 轴上，G 在圆上）：

```
R = (lx² + ly²) / (2·ly) = L² / (2·ly)      （L = 前瞻点实际距离）
κ = 1/R = 2·ly / L²
```

于是角速度：

```
ω = v · κ = v · 2·ly / L²
```

看 `ly` 的符号就懂转向：前瞻点在左（`ly > 0`）→ `κ > 0` → `ω > 0` → 左转。反之右转。这正是"追前瞻点"的几何含义。

例如车位于 `(0,0)`、yaw 为 0，前瞻点为 `(1,0.5)`：

```text
lx = 1.0
ly = 0.5
L = hypot(1.0, 0.5)
kappa = 2 * 0.5 / (1.0^2 + 0.5^2) = 0.8
```

当 `v=1.0 m/s` 时，角速度为 `0.8 rad/s`。由于 `ly > 0`，机器人向左转。

## 五、几个最容易写错的地方

**1. 参考实现中的曲率。** 本仓库提供纯追踪作为参考实现，曲率是 `2·ly / L²`。也可以使用其他控制器。

**2. `ly` 的符号反了。** `ly = -sin(θ)·dx + cos(θ)·dy`，第一项是**负的** `sin`。写成正号，转向就反了——车本该左转结果右转，会原地打转或绕大圈。`verify_tracking` 的横向误差会给出质量提示。

**3. 用错 `L`。** 公式里的 `L` 是**前瞻点的实际距离** `hypot(lx, ly)`，不是标称的 `lookahead_distance`。两者只在车恰好贴着路径时才相等。车一旦偏离，实际距离会大于标称值。

**4. 忘 clamp 角速度。** 车离路径很远时，`ly` 大、`κ` 大、`ω` 可能算出一个天文数字。要把它夹到 `[-max_angular_velocity, max_angular_velocity]`，否则下位机跟不上。

**5. 坐标混用。** 路径是 map 系，车位姿也必须是 map 系（查 TF 得到）。如果位姿用了 odom 系，`dx/dy` 就带了 map->odom 的偏移，转向会错。

### 零距离和单位

如果前瞻点与机器人完全重合，`L²` 为零，曲率计算会产生非有限值。到达判定应在曲率计算前执行；实现还应避免把 NaN 或无穷大速度发给底盘。

本题使用的单位如下：

| 量 | 单位 |
|---|---|
| `lookahead_distance`、`goal_tolerance` | m |
| `max_linear_velocity`、`Command.v` | m/s |
| `max_angular_velocity`、`Command.w` | rad/s |
| `pose.yaw` | rad |

角度参数不能按度数直接传给 `sin` 或 `cos`。

## 六、线速度与到达判定

线速度由两层共同决定：控制器根据目标距离生成逐渐降低的目标速度，执行器再限制每个周期允许的加速和减速幅度。

> **到达判定：车到路径最后一个点（目标）的距离 < `goal_tolerance`，就发 `(0, 0)` 停车。**

`goal_tolerance` 太小（比如 0.01 m）会导致车在目标附近来回震荡、永远到不了（差速底盘有最小转弯半径，没法精确停在一个点上）；太大（比如 1 m）会提前停、离目标还远。本题默认 0.15 m，配合 `verify_reach` 的到达半径 0.3 m。`slowdown_distance` 决定提前多远开始减速。

还有两个安全出口也要处理：

- **路径为空**：直接发 `(0, 0)`；
- **前瞻点就是最后一个点**：车已经快到了，`computeCommand` 里同样按"离终点 < goal_tolerance 就停"处理。

推荐的实现顺序是：

```text
空路径 -> 零速度
终点距离小于容差 -> 零速度
寻找最近点和前瞻点
变换到车体系
计算实际 L 和曲率
按目标距离设置目标线速度
执行器按最大加速度/减速度限制线速度变化
限制角速度
返回 Command
```

## 七、纯追踪的固有缺点

纯追踪的一个特性是**拐角切角**：车追着前瞻点走，在路径的急弯处可能沿拐角内侧行驶。因此地图需要预先膨胀障碍，为跟踪误差保留安全余量（见 `Part_of_Map.md`）。

本题的碰撞判定只认真实障碍（`100`），允许车在代价图的 inflation 区（`1..99`）里轻微切角而不误报。如果你发现 `verify_reach` 报"碰撞"，先想想是不是切角切进了**真实**障碍，而不是 inflation 区。

## 八、小练习

**1.** 路径沿 +x，车在 `(0, 0, θ=0)`，前瞻点 `(1, 0)`。`lx`、`ly`、`κ`、`ω`（`v=1`）各是多少？

**2.** 同样路径，车在 `(0, 1, θ=0)`（路径在车右侧 1 m），前瞻点取最近点 `(0, 0)`。`ly` 和 `ω`（`v=1`）是多少？转向朝哪？

**3.** 车朝 `θ = π/2`（车头朝 +y），前瞻点在车正前方 0.5 m。`lx`、`ly` 各是多少？车会转吗？

<details>
<summary>答案</summary>

**1.** `dx=1, dy=0`，`lx = cos0·1 + sin0·0 = 1`，`ly = -sin0·1 + cos0·0 = 0`，`L = 1`，`κ = 2·0/1 = 0`，`ω = 0`。直线前进。

**2.** 前瞻点 `(0,0)`，`dx=0, dy=-1`，`lx = 0`，`ly = -sin0·0 + cos0·(-1) = -1`，`L = 1`，`κ = 2·(-1)/1 = -2`，`ω = -2`（右转，朝路径转回）。

**3.** 前瞻点在世界系 `(0, 0.5)`（车在原点，正前方 0.5）。`dx=0, dy=0.5`，`lx = cos(π/2)·0 + sin(π/2)·0.5 = 0.5`，`ly = -sin(π/2)·0 + cos(π/2)·0.5 = 0`。`ly=0`，不转。

</details>
