# 标定结果放在这里

脚本运行完成后，本目录下至少应有：

```
result/
├── calibration_result.yaml     # 内参、畸变系数、重投影误差（任务 3）
└── pnp_result.yaml             # 位姿解算结果（任务 5）
```

字段要求见 `../QUESTION.md` 的任务 3 与任务 5。

验证用的图片也放在这里，命名不限，能看出内容即可，例如：

```
result/
├── corners/                    # 角点检测图（可选）
├── undistorted/                # 去畸变前后对比图（可选）
└── pose/                       # 画了坐标轴的位姿图（可选）
```

这部分不强制，但对你判断结果是否正确很有帮助。
